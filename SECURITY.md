# Comunicação de vulnerabilidades

Usa a opção de comunicação privada no separador **Security** do GitHub, se estiver ativa. Se a opção estiver indisponível, contacta em privado a pessoa responsável pelo repositório através de um canal já acordado com a equipa.

Inclui a revisão afetada, o impacto e os passos mínimos para identificar o problema com dados fictícios. Omite segredos e informação pessoal. Reserva as issues públicas para problemas que possam ser discutidos sem expor utilizadores ou sistemas.

Consulta o [guia de segurança e privacidade](docs/security.md) para conhecer os controlos previstos.
